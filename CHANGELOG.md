# Changelog

## [0.1.0] - 2026-08-05

Initial preview release preparation.

- Added a desktop custom editor for CastleDB `.cdb` files.
- Added schema-aware cell editing for common CastleDB types.
- Added sheet, column, row, separator, search, filter, and sort editing tools.
- Added raw JSON recovery and formatting commands.
- Preserved the original CastleDB model sources and license in the source repository.
